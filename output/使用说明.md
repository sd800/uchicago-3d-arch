# 芝加哥大学海德公园校区室外模型

直接双击项目根目录的 `index.html`，用浏览器查看。无需联网或启动服务，网页内嵌模型、三维引擎、标题字体和预览。交互显示需要 WebGL 2 与图形加速；无法启用时显示静态预览，仍可查询建筑与下载 3DS。

界面通常默认英文；首次打开时，设备语言偏好列表中含中文即默认中文。右上角可切换语言，浏览器存储可用时记住手动选择。

## 查看与操作

- 左键拖动旋转，滚轮缩放，右键拖动平移；触屏单指旋转、双指缩放或平移。
- 点击模型或列表选择建筑，查看最高点、占地、东西/南北范围、尺寸依据和来源。
- 支持中英文名称或编号搜索；按区域、地标筛选；逐栋隐藏、定位和单独查看。
- 「全校鸟瞰」「主四合院」「总平面」提供三种视图。地标漫游可快速查看 19 处建筑。
- 环境、建筑外部细节、地标标签和阴影可分别开关；高度截面裁切外部表面，不表示室内楼层。
- 「下载 3DS」导出与交付目录相同的模型；「保存视图」下载当前画布 PNG。

## Rhino 文件与图层

优先打开 `UChicago_HydePark_Layered.3dm`，文件单位为米，保存为 Rhino 7 格式。177 栋建筑各一层，环境全部位于 `环境_Environment` 一层。建筑主体为原生闭合挤出实体，外部细节和景观为闭合网格，并附平面轮廓曲线与命名视图。

`UChicago_HydePark.3ds` 是三角网格格式。3DS 无法完整保留 Rhino 原生图层和实体，应在导入时选米，并通过 Rhino 的 RunPythonScript 运行 `scripts/apply_layers_rhino.py`，按 `layer_map.json` 恢复图层。脚本自动搜索相对路径，也可手动选取 JSON。该脚本需要传统 Rhino Python / IronPython 运行环境，未在本机 Rhino 应用中执行；3DS 已通过独立解析器读回校验。

导入软件可能采用不同的单位或轴向约定。模型 X 东、Y 北、Z 上；请检查洛克菲勒礼拜堂钟塔最高点约 63.09 米等已知尺寸，确认软件未再缩放或交换轴向。

## 尺寸与资料限度

平面采用 OpenStreetMap 地理坐标轮廓，以米制 UTM16N 投影；学校地图用于核对名称和范围。公开资料提供 8 栋建筑的最高高度，Woodlawn 使用公开规划图尺寸，其余 168 栋高度为按层数/功能估算。每栋在网页和 CSV 中分别标识「公开资料高度」「规划图尺寸」「高度估算」。公开最高点并不意味着该栋所有分区标高、窗位或构造均已测量。

模型包括体块、塔楼/退台/坡屋顶等地标特征、示意立面、10 处地图连接体，以及道路、广场、人行路径、草地庭院、运动场、景观树木、少量家具照明和法学院水池。树位、道路宽度、景观配置与屋顶立面细部为近似。地面统一相对 Z=0，无实测地形、室内、地下结构或官方 BIM 数据；适合空间研究和展示，不能作为测绘或施工依据。

`建筑尺寸与来源.csv` 中的宽、深为轴向包围范围，不一定等于立面净尺寸；占地为轮廓面积，最高点包含塔楼或桅杆等。局部 UTM 坐标原点为 WGS84（−87.607，41.782），偏移值见 `model_summary.json`。`footprints_local_meters.geojson` 使用本地投影米制坐标，不能直接当经纬度导入在线地图。

## 文件索引

模型、图层映射、建筑/道路尺寸表、鸟瞰图、总平面图和验证结果在 `output`；可再生成的脚本在 `scripts`，公开地图快照与完整来源索引在 `sources`。字体及其授权在 `assets/fonts`。`UChicago_HydePark_Delivery.zip` 提供便于转交的查看与模型文件。
