# Phoenix and map-scroll logo

The site's white phoenix on a maroon rounded square is adapted from the owner's phoenix-key logo. The final brief preserves the original bird, wings, claws and flowing tail, replacing the key with a compact, fully rolled map scroll. The map is not unfolded.

Generated with the built-in imagegen tool, using the owner's original image as the edit target. The source image in the other project remains untouched.

- `phoenix-map.png`: full-resolution selected artwork, with transparent outer corners.
- `phoenix-map-192.png`: small website header asset.
- `../favicon-32.png`, `../favicon-16.png`, `../apple-touch-icon.png`: browser and device exports.
- `../../favicon.ico`: container of the 16px and 32px PNG exports.

Only size exports were made with macOS sips; no further changes to the drawing. The single-file offline viewer embeds the header and icon assets.

## Final imagegen prompt

Use case: precise-object-edit. EDIT THE ATTACHED ORIGINAL PHOENIX-KEY LOGO, not any newly drawn phoenix. The user wants the exact logo from their other project with ONLY the KEY replaced by a ROLLED-UP MAP SCROLL. Preserve the original phoenix pixel-for-pixel as far as possible: its head, beak, crest, torso, complete wing silhouettes and feather shapes, exact original leg and talon positions, and original flowing tail. Preserve the original maroon rounded-square background and true transparent outer corners, original image size, framing and colors. Do not redesign, elongate or change the bird in any way. Remove the entire existing key, including its big circular ring on the left, the horizontal shaft, and its teeth on the right. In that same horizontal key-shaft position put one neat WHITE CLOSED ROLLED MAP SCROLL, about the original shaft length. It is a compact parchment tube, not an opened sheet. The slim cylindrical middle passes through the EXISTING talons so the same original claws visibly grip it. At each end, a small rolled curl/end cap is defined by a simple maroon negative-space spiral; the ends should remain compact, not oversized like the original key ring. A subtle single curved edge seam can indicate rolled paper. No unfurled map grid, no rectangular paper panel, no bow or ribbon, no text. Keep the scroll at roughly the original key-shaft thickness (approximately 5–6% of the canvas height), so the original legs, belly and tail remain legible. All parts outside the removed-key/new-scroll area must remain visually unchanged. Deliver the finished icon alone.
